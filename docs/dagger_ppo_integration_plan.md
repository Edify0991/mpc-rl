# Phase-2 DAgger + PPO 集成实施方案

本文档是 `Mjlab-MPC-RL-Mimic-Student-Themis` 的**后续实现规范**。当前仓库已经有
`themis_training.dagger_distillation` 中的 DAgger ring buffer、目标损失和单步
supervised update，但 `VelocityOnPolicyRunner` 仍是原生 PPO runner，尚未执行本文所述的
teacher query、数据收集、动作混合或交替更新。

本文的目标是让 Phase-2 student 在只使用本体状态和单帧参考动作的条件下，既从 Phase-1
full-preview MPC-RL teacher 学习，又继续由真实仿真回报优化。训练过程不对 CD-MPC 或仿真器
反向传播。

## 1. 固定接口和符号

在每个 student 环境步的**动作执行前**，从同一个物理状态构造：

\[
o^S_t=\operatorname{Obs}_S(s_t,q^{ref}_{t+1},\dot q^{ref}_{t+1}),
\qquad
o^T_t=\operatorname{Obs}_T(s_t,q^{ref}_{t+1},\dot q^{ref}_{t+1}).
\]

student 的 actor 分布为 \(\pi_S(a\mid o^S_t)\)，其 29 维动作是 normalized joint residual；
teacher 使用**冻结的、评估模式** actor 输出相同动作坐标中的均值：

\[
\bar a^T_t = \mu_T(o^T_t)_{0:29}, \qquad
q^{des}=q^{ref}+0.30a.
\]

其中 `teacher_joint_action_from_full_action` 明确丢弃 Phase-1 teacher 的 \(2H\) 维
contact-plan action。student 不预测、也不蒸馏该 action。teacher 的 MPC landmark 写作
\(z^T_t\)：它必须由 **同一个 \(s_t\)、同一个 reference cursor、同一套 reset/clip mask**
产生，且应在 `env.step()` 前读取。推荐记录的 block 为

\[
z^T_t=[c^{mpc}_{t,1},\dot c^{mpc}_{t,1},k^{mpc}_{t,1},
       f^{mpc}_{t,0},\tau^{mpc}_{t,0},\sigma^{mpc}_{t,0:H-1}],
\]

但首个基础版本可先采用现有的 CoM、角动量、GRF/contact landmarks。所有 landmark 必须有
明确的顺序、维度和 valid mask；不能将已跨越 reference clip 结尾的 horizon tail 当成真实标签。

### teacher 查询的确定性要求

teacher 在 query 时必须：

- 加载固定 checkpoint，并 `eval()`；关闭 dropout、参数梯度和 running-stat 更新；
- 使用 actor 的 **distribution mean** \(\mu_T\)，而不是 `sample()` 的高斯动作；
- 使用 Phase-1 训练时相同的 observation normalization，且不得更新 teacher 的
  normalizer；
- 只执行一次推理；若为了得到 \(z^T_t\) 调用 MPC，其输出也只作 `no_grad` 标签，不能写回
  teacher rollout storage、环境状态或随机数状态；
- 在保存样本前 detach 并检查 `isfinite`。MPC solve 失败、reference tail 无效或 env reset 的
  行必须通过 `teacher_valid_mask=False` 排除。

使用 mean 的原因是 DAgger 的标签应该表示 teacher 的条件决策，而不是其训练期的探索噪声：

\[
\mathbb E_{a\sim\pi_T}[a\mid o]=\mu_T(o).
\]

若用一次采样 \(a_T=\mu_T+\epsilon\) 作 MSE 标签，最优 student 虽仍趋近 \(\mu_T\)，却额外
引入 \(\operatorname{tr}\Sigma_T\) 的标签方差，降低有限 batch 下的样本效率。

## 2. `student rollout → frozen-teacher query` 的严格同步

DAgger 的关键不是让 teacher 独立跑一条轨迹，而是在 student 实际到达的状态上标注：

\[
\mathcal D\leftarrow\mathcal D\cup
\{(o^S_t,\bar a^T_t,z^T_t,m_t)\mid s_t\sim d_{\pi_{\rm mix}}\}.
\]

建议在新 runner 中以以下顺序实现每个 vectorized step。这里的 `cursor` 是每个 env 的 motion
frame index，必须和 `obs` 一起在 step 前 snapshot。

```text
obs_S, state_id, cursor, reset_mask = student_env.current_snapshot()
obs_T, teacher_landmark, valid = teacher_adapter.build_from_same_snapshot(...)
with torch.no_grad():
    teacher_mean = frozen_teacher.actor_mean(obs_T)[:, :29]
    student_sample, student_log_prob, student_value = student.act(obs_S)
append (obs_S, teacher_mean, teacher_landmark, valid, state_id, cursor) to DAgger buffer
action_exec, ppo_valid = choose_teacher_or_student_action(...)
next_obs, reward, terminated, timeout, info = student_env.step(action_exec)
store PPO transition only with the action actually generated by student and ppo_valid=True
```

`teacher_adapter` 是应新增的薄适配层，而不是第二套独立环境。它从 student env 的同一份
root/joint/body/reference state 构造 teacher observation，并调用无副作用的 CD-MPC landmark
builder。必须断言以下量逐 env 相等：`episode_id`、reference clip id、motion frame cursor、
root pose、joint q/dq、reset mask。推荐在 debug 模式保留这些 ID 到 buffer，并每 N 次 rollout
统计不匹配率；它必须为零。

特别注意 off-by-one：样本 \((o_t^S,\bar a^T_t,z_t^T)\) 对应的是 `step(a_t)` **之前**的状态。
不能先 `env.step()` 再用 `o_{t+1}` 给 `a_t` 贴 teacher 标签。对于 auto-reset vector env，
`done=True` 的终止 transition 可留给 PPO bootstrap 规则处理，但不得把 reset 后的 state 与终止前
teacher 标签混在同一条 DAgger 样本中。

## 3. teacher/student 动作混合 \(\beta_j\)

第 \(j\) 个训练 iteration 的 \(\beta_j\) 表示执行 teacher 动作的概率。**不推荐**连续线性混合

\[
a^{exec}=\beta_j\bar a^T+(1-\beta_j)a^S
\]

后仍把 \(a^{exec}\) 作为普通 PPO 样本：其行为分布不是 \(\pi_S\)，标准 PPO 的
\(\pi_\theta(a\mid o)/\pi_{old}(a\mid o)\) 比率不再成立。

基础版本应采用 Bernoulli source mixing：每个 env 在一个 episode 开始时采样
\(b_e\sim\mathrm{Bernoulli}(\beta_j)\)，并在该 episode 内固定：

\[
a^{exec}_t=
\begin{cases}
\bar a^T_t,&b_e=1,\\
a^S_t, &b_e=0.
\end{cases}
\]

两类 episode 都收集 DAgger 标签；但只有 \(b_e=0\) 的 student episode 进入 PPO actor 与 critic
update。teacher episode 只负责把 student 带到较稳定的访问分布，避免将 teacher action 伪装成
student policy 的 on-policy action。实现上需将 `ppo_valid` 传入 rollout storage 的 return、advantage
和 minibatch loss mask；若现有 storage 不支持 mask，则最安全的基础实现是以**完整 rollout 为单位**
只将 student-owned env 送入 PPO update。

后续可将 source choice 从 per-episode 改为 per-step，但一旦 teacher step 混入同一 trajectory，
critic return 对混合行为有偏，须额外实现 masked GAE/trajectory segmentation。因此不应作为第一版。
所有执行 action 在送入环境前仍应按环境已有范围 clip；teacher、student 使用同一 action scale。

一个可用的 schedule 是：

\[
\beta_j=\max\left(0,\beta_0\left(1-\frac{j}{J_\beta}\right)\right),
\quad \beta_0=0.8,\quad J_\beta=0.35J_{total}.
\]

这只是初始值。应记录每 iteration 的 `teacher_episode_fraction` 与实际 `ppo_valid_fraction`；后者
过低时 PPO batch 的有效样本会不足，应该降低 \(\beta\) 或增加并行环境数，而不是静默使用 teacher
transition 做 PPO。

## 4. DAgger/PPO 交替更新

对每个 rollout iteration，建议先固定所有 teacher target，随后交替但不共享 optimizer state：

1. 收集 `N_rollout` 个 student-env step，并按第 2 节写入 replay buffer；
2. 用有效的 student-owned transitions 计算 GAE，执行 `K_ppo` 个标准 PPO epoch；
3. 从 DAgger buffer 随机采样，执行 `K_dagger` 个 supervised minibatch update；
4. 记录 PPO 与 DAgger 指标，再更新 \(\lambda_{DAgger}\) 和 \(\beta\)。

PPO 与 supervised loss 都会更新 student actor，因此有两种实现选择：

- **推荐的基础实现：同一个 actor、两个 optimizer step。** PPO optimizer 先更新 actor/critic；
  随后由独立的 `dagger_optimizer` 更新 actor 和 optional landmark head。不要让 landmark head
  误连到 critic；critic 仅由 PPO value loss 训练。
- **单一联合 loss（后续项）：** 在 PPO minibatch 上加 supervised loss。
  这要求 DAgger 样本和 PPO storage 的索引、mask 严格对齐，且改变 PPO 的每个 epoch objective；
  不建议作为第一版。

第一版的默认比例可为 `K_ppo=5`、`K_dagger=2`，每个 DAgger minibatch 取 PPO minibatch 的
1--2 倍。buffer 容量宜覆盖最近 20--50 个 rollout，而非无限累计；过旧的 teacher 标签对应的
状态分布已远离当前 student。可采用 `recent_fraction=0.75`：75% 样本来自最近 5 个 rollout，
25% 从其余 ring buffer 随机抽取，以兼顾当前访问分布和灾难性遗忘。

联合目标仅用于概念说明：

\[
\mathcal L = \mathcal L_{PPO}^{actor}+c_v\mathcal L_{value}
-c_e\mathcal H(\pi_S)+\lambda_{DAgger,j}\mathcal L_{DAgger}.
\]

在“两个 optimizer step”版本中，\(\lambda_{DAgger,j}\) 由 DAgger optimizer 的 loss 权重或
学习率等效实现；日志中仍应报告它，保证实验可复现。

## 5. \(\lambda_{DAgger}\) annealing

定义归一化后的辅助损失（见下一节）后：

\[
\mathcal L_{DAgger}=
\lambda_q\lVert a_S-\bar a_T\rVert^2+
\lambda_z\lVert \tilde z_S-\tilde z_T\rVert^2.
\]

建议 \(\lambda_q=1\)，\(\lambda_z=0.05\) 起步，采用有下限的余弦退火：

\[
\lambda_{DAgger,j}=\lambda_{min}+
\tfrac12(\lambda_{max}-\lambda_{min})
\left[1+\cos\left(\pi\min\left(1,\frac{j}{J_\lambda}\right)\right)\right],
\]

其中 \(\lambda_{max}=1\)、\(\lambda_{min}=0.05\)、\(J_\lambda=0.6J_{total}\)。保留小的下限
使训练后期仍有 teacher anchor，避免 PPO 在困难 reference 片段中完全漂移。若最终目标是只由
环境回报决定，才将 \(\lambda_{min}=0\)。

退火不应只按 global iteration 盲目进行：应同时观察 validation clip 上的 mimic reward、fall rate、
joint-action MSE 和 landmark NRMSE。若 `fall_rate` 回升或 DAgger MSE 突增，可暂缓退火；这属于
预先定义的 curriculum 规则，必须写入实验配置与日志，不应根据测试曲线临时调参。

## 6. landmark normalization 与损失构造

CoM（m）、速度（m/s）、角动量（kg m^2/s）、力（N）、力矩（N m）和 contact activation
的量纲不同，不能对原始拼接向量直接 MSE。为每个连续 landmark dimension 维护仅由**有效 teacher
标签**更新的冻结/EMA 统计量：

\[
\tilde z_d=\frac{z_d-\mu_d}{\max(\sqrt{v_d},s_{min,d})}.
\]

统计量应在样本写入 buffer 时保存对应的 normalized target，或保存 raw target 及其 `stats_version`；
不能在历史 buffer 上每次用变化后的 \(\mu,v\) 重新解释旧数据。最简单且稳定的实现是：

1. Phase-2 warm-up 的若干 teacher query 收集有效 raw labels，初始化 `mean/std`；
2. 固定该 normalizer 一整个训练 run；
3. buffer 中只存 normalized `teacher_landmark` 与 bool mask；
4. student auxiliary head 输出同样的 normalized 坐标，部署时丢弃该 head。

推荐以 block 而非单一向量加权：

\[
\mathcal L_z =w_c\operatorname{MSE}(\tilde c)+w_v\operatorname{MSE}(\tilde{\dot c})+
w_k\operatorname{MSE}(\tilde k)+w_f\operatorname{MSE}(\tilde f)+
w_\tau\operatorname{MSE}(\tilde\tau)+w_\sigma\operatorname{BCE}(\hat\sigma,\sigma).
\]

其中 contact \(\sigma\) 是 \([0,1]\) 标签，使用 logits + BCE（并依据 valid stage mask），而不是和物理量
共同 z-score。初始可设所有连续 block \(w=1\)，而整体 landmark 项用 \(\lambda_z=0.05\)；再用
validation NRMSE 调整。若 force/torque 来自 teacher QP 而目标 task 不要求 reconstruct 它们，
可先令 \(w_f=w_\tau=0\)，逐步消融，避免过度约束 student。

`DaggerReplayBuffer` 目前保存一个未归一化的扁平 landmark tensor，`dagger_distillation_loss` 也只做
单一 MSE。因此接入本文方案时必须新增 `LandmarkNormalizer`、连续/block slice、contact mask/BCE，
不能仅在 config 中调大 `landmark_weight`。

## 7. 建议新增的 runner/config 结构

不要修改通用 `VelocityOnPolicyRunner` 的语义。新增例如
`ThemisDaggerPpoRunner(VelocityOnPolicyRunner)`，只供
`Mjlab-MPC-RL-Mimic-Student-Themis` 注册使用。建议配置项：

```python
DaggerPpoCfg(
    teacher_checkpoint: str,
    teacher_task_id: "Mjlab-MPC-RL-Mimic-Contact-Themis",
    replay_capacity: int,
    dagger_batch_size: int,
    dagger_updates_per_iteration: int,
    ppo_epochs: int,
    beta_start: float = 0.8,
    beta_end: float = 0.0,
    beta_anneal_iterations: int,
    lambda_dagger_start: float = 1.0,
    lambda_dagger_end: float = 0.05,
    lambda_dagger_anneal_iterations: int,
    landmark_warmup_steps: int,
    landmark_blocks: ...,  # slices, units, continuous/contact type and masks
    deterministic_teacher: bool = True,
)
```

runner 初始化应显式验证：teacher/student 的 joint action dimension 均为 29、残差 scale 均为
0.30、motion reference joint order 一致、teacher checkpoint 的 observation normalizer 存在、
reference clip source 可被 `teacher_adapter` 访问。任何一项不一致都应报错，不能悄悄截断或重排。

## 8. 验证、日志和消融

在开始大规模训练前，至少做以下单元/集成验证：

- 同一 snapshot 下 adapter 重建的 teacher observation 与 teacher 环境原 observation 的最大误差
  小于浮点容差；clip id/cursor/reset mask 完全一致；
- teacher `mean` 在重复 query 中逐元素一致；切换到 `sample` 时方差非零，验证 deterministic 分支
  确实生效；
- `ppo_valid=False` 的 teacher episode 不参与 actor、critic、GAE 和 PPO entropy 的分母；
- all-student（\(\beta=0\)）时新 runner 的 PPO loss/return 与原 runner 在固定随机种子下等价；
- normalized landmark 在 valid 样本上均值约为 0、标准差约为 1；无效 tail、MPC failure 和 reset
  样本不影响统计量或 loss；
- checkpoint reload 后 student 的 deployment path 不依赖 teacher、MPC、landmark head 或 future
  contact plan。

每次 iteration 记录：PPO return/value/explained variance/KL/clip fraction，DAgger joint MSE、每个
landmark block 的 NRMSE/BCE、buffer age、teacher valid fraction、teacher episode fraction、PPO
valid fraction、\(\beta_j\)、\(\lambda_{DAgger,j}\)、teacher/student action norm、fall rate 和每个
reference clip 的成功率。论文实验至少报告：纯 PPO student、纯 behavior cloning、DAgger-only、
PPO+DAgger（无 landmark）、PPO+DAgger（完整 landmark），以及不同 \(\beta\)/\(\lambda\) schedule
的消融。

## 9. 实现边界

这套方法是“特权 teacher 的 DAgger 辅助 + on-policy PPO”，不是端到端穿过 MPC 的 model-based
policy gradient，也不为 CD-MPC 的最优性或 student 的稳定性提供一般性理论保证。它的正确性依赖于：
teacher 在训练目标分布上足够有效、snapshot 同步正确、PPO 不使用 teacher-forced transition 作为
student on-policy 数据，以及部署观测确实不含 future reference 或 MPC 特权信息。上述边界应在代码和
实验报告中保持明确。
